Motion Equation Program

Physics gives us formulas that describe how the world works. In this lesson, you'll write a Python program to solve the motion equation: s = ut + ½at². You'll use variables, conditions, and loops to make your program powerful and flexible.

Warm-Up: Physics Review

Let's review the motion equation before we write the program:

Motion Equation
s = u × t + ½ × a × t²

Here's what each variable means:

📏

s = Displacement

How far the object has moved, in meters (m).

🚀

u = Initial Velocity

The starting speed of the object, in m/s.

⏱️

t = Time

How long the object has been moving, in seconds (s).

⚡

a = Acceleration

How quickly the velocity changes, in m/s².

💡
What does this formula calculate? Given an object's starting velocity (u), acceleration (a), and time (t), it tells you how far the object has traveled (s).
Build the Program

Let's write the Python program step by step:

Python Program
u = float(input("Initial velocity (m/s): "))
a = float(input("Acceleration (m/s²): "))
t = float(input("Time (s): "))

s = u * t + 0.5 * a * t * t

print("Displacement =", s, "m")

Let's break it down:

  • Line 1: Ask the user for the initial velocity (u).
  • Line 2: Ask the user for the acceleration (a).
  • Line 3: Ask the user for the time (t).
  • Line 5: Calculate displacement using the formula.
  • Line 7: Print the result with units.

Sample calculation:

If u = 0, a = 9.8, and t = 2:

  • s = 0 × 2 + 0.5 × 9.8 × 2 × 2
  • s = 0 + 0.5 × 9.8 × 4
  • s = 0 + 19.6 = 19.6 m
💡
This is exactly what happens when you drop an object from rest (u = 0) and it falls for 2 seconds. Gravity accelerates it at 9.8 m/s². After 2 seconds, it has fallen 19.6 meters.

Adding Conditions

Our program works, but what if the answer is negative? A negative displacement means the object moved backwards. Let's add a condition to check:

Python with Condition
u = float(input("Initial velocity (m/s): "))
a = float(input("Acceleration (m/s²): "))
t = float(input("Time (s): "))

s = u * t + 0.5 * a * t * t

print("Displacement =", s, "m")

if s < 0:
    print("Object moved backwards.")
else:
    print("Object moved forwards.")
💡
Why add this check? Because we want the program to explain the result, not just print a number. A negative displacement means the object ended up behind where it started.
Adding a Loop

What if we want to see how displacement changes over time? Let's use a for loop to calculate displacement at multiple times:

Python with Loop
u = float(input("Initial velocity (m/s): "))
a = float(input("Acceleration (m/s²): "))

for i in range(5):
    t = float(input("Time (s): "))
    s = u * t + 0.5 * a * t * t
    print("At t =", t, "s, displacement =", s, "m")

This program asks for 5 different times and calculates the displacement for each one. It's perfect for creating a table of results or a graph.

💡
Try it with these values: u = 5, a = 2. Then use times 1, 2, 3, 4, 5. You'll see the object speeding up over time.

Testing the Program

Testing is essential! Let's try the program with different inputs:

Test u (m/s) a (m/s²) t (s) Expected
Falling from rest 0 9.8 2 19.6 m
Moving at constant speed 5 0 3 15.0 m
Speeding up 2 3 4 32.0 m
Slowing down 10 -2 3 21.0 m
Moving backwards 0 -5 2 -10.0 m

Run your program with each test case. Does it give the expected results? If not, check your formula and make sure units match.

💡
Notice the 4th test: A negative acceleration means the object slows down. The 5th test: a very negative acceleration can make the object move backwards.

Key Takeaway

The motion equation (s = ut + ½at²) is a perfect problem for a Python program. By combining variables (u, a, t, s), conditions (checking if displacement is negative), and loops (repeating calculations for different times), you can build a powerful tool that solves physics problems automatically. Always test your program with different inputs to make sure it works correctly. Next lesson, you'll build a similar program to calculate the area of different shapes!
