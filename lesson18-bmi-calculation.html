BMI Calculation Program

In this lesson, you'll build a real-world health tool: a BMI (Body Mass Index) calculator. You'll use everything you've learned — variables, conditions, and input validation — to write a program that calculates BMI and tells the user their health category.

Warm-Up: What is BMI?

BMI stands for Body Mass Index. It's a number that helps doctors and health professionals understand whether a person's weight is healthy for their height.

BMI Formula
BMI = weight (kg) ÷ height² (m²)

BMI Categories:

  • BMI < 18.5: Underweight
  • 18.5 ≤ BMI < 25: Normal
  • 25 ≤ BMI < 30: Overweight
  • BMI ≥ 30: Obese
💡
Why does this matter? BMI helps people understand their health. But remember — it's just one measure, and not perfect for athletes or growing children.
Build the Basic BMI Program

Let's start with a simple version that just calculates BMI:

Python — Basic Version
w = float(input("Weight (kg): "))
h = float(input("Height (m): "))

bmi = w / (h * h)

print("BMI =", bmi)

Let's trace through with an example:

  • Weight = 50 kg, Height = 1.6 m
  • h² = 1.6 × 1.6 = 2.56
  • BMI = 50 ÷ 2.56 = 19.5
💡
Why use float for both? Because weight and height can be decimals (like 1.6 m or 52.5 kg). Using float makes the program work for everyone.

Adding BMI Categories

A BMI number alone doesn't tell the user much. Let's add if/elif/else to print the correct category:

Python — With Categories
w = float(input("Weight (kg): "))
h = float(input("Height (m): "))

bmi = w / (h * h)
print("BMI =", bmi)

if bmi < 18.5:
    print("Category: Underweight")
elif bmi < 25:
    print("Category: Normal")
elif bmi < 30:
    print("Category: Overweight")
else:
    print("Category: Obese")

How the categories work:

  • If BMI is 19.5: 19.5 < 18.5 is False, 19.5 < 25 is True → prints "Normal"
  • If BMI is 15.0: 15.0 < 18.5 is True → prints "Underweight"
  • If BMI is 27.0: 27.0 < 30 is True → prints "Overweight"
  • If BMI is 35.0: All conditions False → prints "Obese"

Adding Input Validation

What happens if the user types a negative height or a zero height? The program will either crash or give a wrong answer. Let's fix that!

Python — With Validation
w = float(input("Weight (kg): "))
h = float(input("Height (m): "))

if h <= 0:
    print("Error: Height must be greater than zero!")
elif w <= 0:
    print("Error: Weight must be greater than zero!")
else:
    bmi = w / (h * h)
    print("BMI =", bmi)
    # ... categories
💡
Why validate? Because good programs don't crash on bad input — they explain the problem and let the user try again.
Adding a Loop for Multiple People

What if you want to calculate BMI for 3 friends in one run? Use a for loop!

Python — With Loop
for i in range(3):
    print("Person", i + 1)
    w = float(input("Weight (kg): "))
    h = float(input("Height (m): "))
    bmi = w / (h * h)
    print("BMI =", bmi)
    print()

What this does:

  • The loop runs 3 times (once for each person).
  • Each time, it asks for weight and height, then calculates and prints BMI.
  • The print() at the end adds a blank line, so the output is easier to read.
💡
Try changing the number! Replace range(3) with range(10) to calculate BMI for 10 people in one run.

Activity — Think About Limitations

Consider these questions:

  1. Why might an athlete have a high BMI but still be very healthy?
  2. Why is BMI not a good measure for young children?
  3. What other health measures might be more useful than BMI?
