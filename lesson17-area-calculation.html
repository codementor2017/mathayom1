Area Calculation Program

In the last lesson, you built a program for one formula. Now, let's build a program that handles many formulas — one for each shape! You'll learn how to use conditions (if/elif/else) to let the user choose the shape, and how to calculate areas of rectangles, triangles, circles, and more.

Warm-Up: Area Formulas Review

Let's review the area formulas we'll be using:

Shape Formula
Rectangle Area = length × width
Triangle Area = 0.5 × base × height
Circle Area = π × radius²
Square Area = side × side
Parallelogram Area = base × height
Trapezoid Area = 0.5 × (a + b) × height
💡
Challenge: Can we write one program that calculates areas for all of these shapes? Yes — with if/elif/else!
Build the Program — Step by Step

Let's build a program that asks the user which shape they want, then calculates the correct area.

Step 1 — Ask the user to choose a shape:

Python
choice = input("Shape (rectangle/triangle/circle): ")

Step 2 — Use if/elif/else to handle each shape:

Python
if choice == "rectangle":
    l = float(input("Length: "))
    w = float(input("Width: "))
    print("Area =", l * w)

elif choice == "triangle":
    b = float(input("Base: "))
    h = float(input("Height: "))
    print("Area =", 0.5 * b * h)

elif choice == "circle":
    r = float(input("Radius: "))
    print("Area =", 3.14159 * r * r)

else:
    print("Unknown shape")

How it works:

  • If the user types "rectangle", the program asks for length and width, then calculates.
  • If the user types "triangle", it asks for base and height.
  • If the user types "circle", it asks for radius.
  • If the user types something else, it prints "Unknown shape".
💡
The magic of if/elif/else: The user chooses the path, and the program follows the right one. This is how one program can handle many different cases!

Using the Math Library for Precision

In the circle example, we wrote 3.14159 for π (pi). That's a decent approximation, but Python has a built-in math module that gives us the exact value of π:

Python with math module
import math

r = float(input("Radius: "))
area = math.pi * r * r
print("Area =", area)

What's happening?

  • import math — brings the math library into our program.
  • math.pi — gives us the value of π (about 3.14159265…).
  • The result is more precise than using 3.14 or 3.14159.
💡
Tip: For real-world calculations, always use math.pi — not 3.14. Small differences can add up!
Adding More Shapes

Now let's add more shapes to our program. Just add more elif branches!

Python — Extended Program
import math

choice = input("Shape (rectangle/triangle/circle/square/parallelogram/trapezoid): ")

if choice == "rectangle":
    l = float(input("Length: "))
    w = float(input("Width: "))
    print("Area =", l * w)

elif choice == "triangle":
    b = float(input("Base: "))
    h = float(input("Height: "))
    print("Area =", 0.5 * b * h)

elif choice == "circle":
    r = float(input("Radius: "))
    print("Area =", math.pi * r * r)

elif choice == "square":
    s = float(input("Side: "))
    print("Area =", s * s)

elif choice == "parallelogram":
    b = float(input("Base: "))
    h = float(input("Height: "))
    print("Area =", b * h)

elif choice == "trapezoid":
    a = float(input("Side a: "))
    b = float(input("Side b: "))
    h = float(input("Height: "))
    print("Area =", 0.5 * (a + b) * h)

else:
    print("Unknown shape")
💡
Notice the pattern: Each branch has the same structure — ask for inputs, calculate, print the result. Only the formula changes.

Your Turn — Add Input Validation

Our program works, but what if the user enters a negative number? For example, a length of -5 doesn't make sense for a rectangle!

Let's fix that with input validation:

Example — Rectangle with Validation
if choice == "rectangle":
    l = float(input("Length: "))
    w = float(input("Width: "))
    if l <= 0 or w <= 0:
        print("Length and width must be positive!")
    else:
        print("Area =", l * w)

Your task:

  1. Add the same validation to the triangle branch.
  2. Add the same validation to the circle branch.
  3. Add the same validation to the square branch.
  4. Test your program with negative numbers. Does it print the warning?
💡
Why validate? Because a good program handles bad input gracefully — it doesn't just crash or give a wrong answer.

Key Takeaway

The Area Calculation Program shows how one program can handle many different cases using if/elif/else. Each branch asks for the right inputs and applies the right formula. Adding input validation makes the program more robust, and adding a loop makes it reusable. This pattern — choose the branch, apply the right formula — appears in many real programs.
