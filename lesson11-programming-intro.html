Introduction to Programming and Algorithms

Welcome to Indicator 2! In this unit, you'll learn how to write real computer programs in a language called Python. But before we write code, we need to understand two important ideas: what is a program? and what is an algorithm?

What is a Program?
Definition
A program is a set of instructions that a computer follows to solve a problem.

Every program has three parts:

📥

1. Input

Information the program receives. Example: numbers from the user.

⚙️

2. Process

The steps the program does with the input. Example: multiply two numbers.

📤

3. Output

The result the program shows. Example: display the answer.

💡
Input → Process → Output. Every program — from a calculator to a video game — follows this pattern.

What is an Algorithm?
Definition
An algorithm is a clear, ordered set of steps to solve a problem.

You already learned about algorithms in Indicator 1! Here's a simple example:

Algorithm — Find the area of a rectangle:

  1. Input length and width.
  2. Multiply length × width.
  3. Output the area.
💡
Algorithms are the plan. Programs are the plan written in code. You can think of the algorithm as the recipe, and the program as the finished dish.
Algorithms in Math & Science

Many math and science problems can be solved with programs. Here are some examples:

Problem Algorithm (Steps)
Area of a rectangle Input length and width → Multiply → Output area
Speed from distance & time Input distance, time → Divide → Output speed
Convert Celsius to Fahrenheit Input Celsius → (C × 9/5) + 32 → Output Fahrenheit
Force (F = ma) Input mass, acceleration → Multiply → Output force
Volume of a cube Input side length → side × side × side → Output volume
💡
Every one of these can be written as a program. Once you learn to write code, you can automate these calculations.

Same Algorithm, Different Languages

An algorithm can be written in any programming language. Here's the same algorithm (area of a rectangle) written in Python:

Python Code
length = float(input("Enter length: "))
width = float(input("Enter width: "))
area = length * width
print("Area =", area)

Let's break it down line by line:

  • Line 1: Ask the user for the length. The user types a number.
  • Line 2: Ask the user for the width.
  • Line 3: Multiply length × width and store it in area.
  • Line 4: Print the result.
💡
Key idea: The algorithm is the same in every language. The program is just the algorithm written in a specific language.

Guided Practice: From Problem to Steps

Let's write an algorithm together for a simple science problem: "Calculate speed given distance and time."

Step-by-step algorithm:

  1. Input the distance traveled.
  2. Input the time it took.
  3. Calculate speed = distance ÷ time.
  4. Output the speed.

The same algorithm in pseudocode:

Pseudocode
START
  INPUT distance, time
  speed = distance ÷ time
  PRINT speed
END

Second problem — Convert Celsius to Fahrenheit:

Formula: F = (C × 9/5) + 32

  1. Input Celsius temperature.
  2. Calculate F = (C × 9/5) + 32.
  3. Output the Fahrenheit temperature.

Your Turn — Write Your Own Algorithm

Work with a partner. Choose one of the problems below and write a step-by-step algorithm and pseudocode.

📐

Perimeter of a Square

Perimeter = side × 4

📊

Average of 3 Scores

Average = (score1 + score2 + score3) ÷ 3

⚙️

Force from Mass & Acceleration

F = mass × acceleration

📦

Volume of a Cube

Volume = side × side × side

Your algorithm should:

  1. Have clear Input steps.
  2. Have a clear Process step (calculation).
  3. Have a clear Output step.
  4. Be written as pseudocode with START and END.

Activity — Share and Discuss

After you finish, swap your work with another pair. Review their algorithm carefully.

Ask each other:

  1. Is the algorithm clear? Can someone follow it exactly?
  2. Is the order correct?
  3. Are the inputs, processes, and outputs all present?
  4. Are there any missing steps?

Discuss with the class:

  • Why is step-by-step problem solving efficient?
  • What is the difference between an algorithm and a program?
💡
Key insight: Clear steps → efficient solution. Writing the algorithm before writing the code saves time and prevents mistakes.

Key Takeaway

A program is a set of instructions a computer follows. Every program has three parts: Input, Process, and Output. An algorithm is the plan — a clear, ordered set of steps. You can write an algorithm in any language (pseudocode, Python, Java, etc.). Next lesson, you'll learn about variables and data types in Python — the building blocks of any program!
