Introduction to Data Presentation & Visualization

A picture is worth a thousand numbers! In this lesson, you'll learn how to turn your processed data into charts and graphs that make your findings easy to understand at a glance. You'll discover which chart type works best for different kinds of data.

Why Do We Visualize Data?

Imagine you have a table with 100 numbers. Now imagine the same data shown as a colorful chart. Which is easier to understand?

Charts and graphs help us:

  • See patterns quickly (trends, peaks, drops)
  • Compare values side by side
  • Communicate findings to others clearly
  • Make decisions faster based on visible evidence
💡
Key idea: A good chart tells a story. Before you make a chart, ask yourself: "What do I want my reader to notice?"
The Three Main Chart Types

There are three chart types you'll use most often. Each one is best for a specific kind of data.

📊

Bar Chart

Best for comparing categories. Each bar shows the value for a different group.

🥧

Pie Chart

Best for showing parts of a whole. Each slice is a percentage of the total.

📈

Line Graph

Best for showing change over time. Points are connected to show a trend.

When to Use Each Chart Type

Use this table to help you choose the right chart for your data.

Chart Type Best For Example Question
📊 Bar Chart Comparing categories or groups "Which fruit is the most popular?"
🥧 Pie Chart Showing parts of a whole (100%) "What percentage of students prefer each fruit?"
📈 Line Graph Showing change over time "How did the temperature change during the day?"
💡
Tip: Don't mix them up! A bar chart is NOT the same as a line graph. If your data is about categories, use a bar chart. If your data is about time, use a line graph.
Rules for Great Charts

A chart with missing labels or confusing colors won't help anyone. Follow these 5 rules for every chart you make:

  1. Give your chart a clear title.
    Example: "Favourite Fruits in Class 7A" — not just "Chart 1".
  2. Label your axes.
    The horizontal axis (x-axis) and vertical axis (y-axis) both need labels so we know what the numbers mean.
  3. Include units.
    If your chart shows temperature, write "°C". If it shows hours, write "hours".
  4. Use a legend if needed.
    For pie charts or multi-series charts, a legend explains what each color or symbol means.
  5. Choose clear colors.
    Use distinct colors so categories don't blend together. Avoid using too many colors.

Creating a Chart with a Spreadsheet

You can draw charts by hand, but spreadsheets (like Google Sheets or Excel) make it easy. Here's the simple 5-step process:

  1. Enter your data into the spreadsheet — one column for labels, one column for values.
  2. Select the data with your mouse (highlight the cells).
  3. Insert → Chart from the menu (or click the chart icon).
  4. Choose the chart type — bar, pie, or line.
  5. Add a title, labels, and legend — then preview and adjust the colors if needed.
💡
Try it: Open Google Sheets, type in a few numbers, select them, and insert a chart. Play with the different chart types to see which one fits best!

Worked Example — From Data to Chart

Let's say your class surveyed 20 students about their favourite fruit. Here are the results:

Fruit Number of Students Percentage
🍎 Apple630%
🍌 Banana420%
🍇 Grapes735%
🥭 Mango315%

Which chart should we use?

  • We want to compare categories (fruits) → Bar Chart works great!
  • We want to show parts of a whole (percentages that add to 100%) → Pie Chart is perfect!
💡
Notice: Both charts use the same data, but they tell the story differently. A bar chart compares; a pie chart shows proportion.

Key Takeaway

Charts turn numbers into stories. Use a bar chart to compare categories, a pie chart to show parts of a whole, and a line graph to show change over time. Always include a title, labels, units, and a legend so your reader understands your data at a glance.
