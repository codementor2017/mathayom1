Essential vs Non-Essential Details

In Lesson 1, you learned that abstraction means focusing on the important details for a goal. But how do you actually decide if a detail is important? In this lesson, you'll learn three simple questions that help you sort details into essential and non-essential — no more guessing!

Quick Review from Lesson 1

Before we dive deeper, let's remind ourselves of the big idea:

  • Abstraction = focusing on important details and ignoring unimportant ones for a specific goal.
  • Abstraction does not mean removing everything.
  • The goal decides what is essential.
  • If the goal changes, the important details change too.
💡
Today's focus: How do we decide which details are essential? Is there a way to test each detail instead of guessing?
The Three Questions for Essential Details

Ask these three questions about any detail. If the answer to any question is "yes," the detail is essential.

1️⃣

Does it change the goal?

If removing this detail changes the goal, it's essential.

2️⃣

Does it change the steps?

If removing this detail changes the steps you need to take, it's essential.

3️⃣

Does it change the answer?

If removing this detail changes the final answer or result, it's essential.

❌

If "no" to all three…

…the detail is non-essential. You can safely ignore it.

The Rule
Essential = changes goal, steps, or answer.
Non-essential = changes nothing.

Worked Example: Class Party Snacks

Scenario: You're buying snacks for a class party for 30 students. The budget is 1,500 baht. Two students are allergic to peanuts.

Let's apply the three questions to each detail:

Detail Changes goal? Changes steps? Changes answer? Essential?
Number of students (30) No No Yes — how much to buy ✅ Essential
Budget (1,500 baht) No No Yes — what you can afford ✅ Essential
Peanut allergy No Yes — avoid certain snacks Yes — safety of students ✅ Essential
Snack color No No No ❌ Non-Essential
Snack brand No No No ❌ Non-Essential
Weather No No No ❌ Non-Essential
Type of snack No No Yes — students need to enjoy it ✅ Essential
💡
Notice: "Snack color" and "snack brand" don't change anything important. They're just details we can safely ignore.

More Examples to Practice

Here are more scenarios. For each one, think about which details are essential.

Scenario 1 — Packing for a school trip

  • Essential: Number of days, weather, activities planned
  • Non-essential: Color of your suitcase, brand of your shoes

Scenario 2 — Planning a birthday party

  • Essential: Number of guests, budget, location, date
  • Non-essential: Color of the napkins, type of music playing

Scenario 3 — Buying a phone

  • Essential: Budget, needs (camera, storage, battery), phone size
  • Non-essential: Color of the case, brand of the charger
💡
Watch out: "Store location" might be non-essential — unless delivery time matters. That's why we always come back to the goal.

Activity — Same Detail, Different Problem

A detail can be essential in one problem and non-essential in another. Let's explore this idea with the examples below.

Detail Essential When… Non-Essential When…
Store location You need the snacks delivered quickly You can pick them up anytime
Weather You're planning an outdoor event The event is indoors
Color of napkins You're decorating for a themed party Guests only care about the food
Number of helpers The task is big and time is short The task is small and one person can do it
Brand of tools You need professional quality for a long project Any working tool will do

Now answer these questions in your notebook:

  1. Pick one detail from the table above. Write two different scenarios where it's essential vs non-essential.
  2. Think of your own example of a detail that is essential in one situation but non-essential in another.
  3. Explain why using the three questions.

Check Your Understanding

Answer these questions in your notebook:

  1. What are the three questions for testing if a detail is essential?
  2. If a detail doesn't change the goal, steps, or answer — is it essential? Why or why not?
  3. Give one example of a non-essential detail for a class party, and explain why.
  4. Can a detail be essential in one problem but non-essential in another? Give one example.
  5. Why does removing non-essential details make a problem easier to solve?
  6. Why is abstraction not permanent — why does it depend on the goal?

Key Takeaway

Use the three questions to decide if a detail is essential: Does it change the goal, the steps, or the answer? If yes, keep it. If no, you can safely ignore it. Remember — abstraction isn't permanent. The same detail can be essential in one problem and non-essential in another. The goal decides. Homework

Part 1 — Rewrite a messy problem:

Here's a messy problem statement with lots of non-essential details:

📄
"I want to buy a new pencil. The pencil is blue. The shop is far away. The pencil costs 10 baht. The shop has a cat. I need it for writing."

Your task:

  • Identify the non-essential details and cross them out.
  • Rewrite the problem using only the essential details.
  • Write one sentence explaining why you kept the details you kept.

Part 2 — Find your own example:

  • Write a short paragraph about a real-life decision (choosing a snack, planning a trip, etc.).
  • Include 3 essential details and 3 non-essential details.
  • Use the three questions to justify each choice.
