Variables and Data Types

In Lesson 11, you learned that every program has input, process, and output. But where does the data go in between? That's where variables come in! In this lesson, you'll learn what variables are, what data types they can store, and how to use them in Python.

Warm-Up: What is a Variable?

In math class, you learned that a variable is a letter that represents a number — like x = 5. In programming, a variable is similar but more powerful.

💡
In programming, a variable is a named storage location for a value. You give it a name, and it stores a value that you can use later.

Think of a variable as a labeled box. You write a name on the box (like radius), and you put a value inside (like 5).

Variables in Python

In Python, you create a variable by giving it a name and assigning a value with the = sign.

Python Example
radius = 5
pi = 3.14
name = "Somsak"

Here's what each line does:

  • radius = 5 — creates a variable called radius and stores the value 5.
  • pi = 3.14 — creates a variable called pi and stores the value 3.14.
  • name = "Somsak" — creates a variable called name and stores the text "Somsak".
💡
Tip: Choose clear variable names! radius is much better than r or x. Future-you will thank present-you.

The Three Data Types You Need to Know

A data type tells the computer what kind of value a variable holds. In Python, there are three main data types you'll use in math and science:

🔢

Integer (int)

Whole numbers — no decimal point.

Examples: 5, -3, 100, 0, 42

🔟

Float

Decimal numbers — with a decimal point.

Examples: 3.14, 0.5, -2.7, 100.0

💬

String (str)

Text — letters, words, or sentences.

Examples: "hello", "cm", "Somsak", "5 apples"

Python Examples
length = 10 # integer
width = 2.5 # float
unit = "cm" # string

Why Do Data Types Matter?

Choosing the right data type is important because you can only do certain operations with certain types.

Example — What happens if we mix types?

❌ Wrong
area = "10" * 2.5
# Error! Can't multiply a string by a float.
✅ Correct
area = 10 * 2.5
# Works! 10 is an integer, 2.5 is a float.
# Result: 25.0 (a float)
💡
Rule of thumb: If you're doing math, use int or float. Use str only for text — like labels or units.
Choosing the Right Data Type

Here's a table to help you choose the right data type for a math or science problem:

What You're Storing Data Type Example
Number of students integer (int) students = 30
Length of a table float length = 2.5
Unit of measurement string (str) unit = "cm"
Name of a student string (str) name = "Somsak"
Weight in kilograms float weight = 45.5
Number of books integer (int) books = 12
💡
Ask yourself: "Is this a whole number, a decimal, or text?" That tells you which data type to use.

Guided Practice: Variables for Area

Let's write a Python program together to calculate the area of a rectangle:

Python Program
length = float(input("Enter length: "))
width = float(input("Enter width: "))
area = length * width
print("Area =", area)

Let's break it down:

  • length = float(input("Enter length: "))
    Ask the user for the length, convert it to a float (so we can use decimals), and store it in length.
  • width = float(input("Enter width: "))
    Ask the user for the width, convert it to a float, and store it in width.
  • area = length * width
    Multiply length × width, and store the result in area.
  • print("Area =", area)
    Display "Area = " followed by the value of area.
💡
Why float and not int? Because length and width could be decimals (like 2.5 m). Using float makes the program work for both whole numbers and decimals.

Key Takeaway

A variable is a named storage location for a value. Every variable has a data type: integer (whole numbers), float (decimals), or string (text). Choosing the right data type matters because you can only do certain operations with certain types. For math and science, use int or float — float if decimals are possible.
