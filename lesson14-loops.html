Loops (for/while) for Repetition

Imagine printing the numbers 1 to 100. Would you write 100 print statements? Of course not! In this lesson, you'll learn how to use for and while loops to make your programs repeat steps automatically — saving time and preventing mistakes.

Why Do We Need Loops?

Imagine you want to print the numbers 1 to 5. You could write this:

❌ Without Loops
print(1)
print(2)
print(3)
print(4)
print(5)

That works for 5 numbers. But what if you wanted to print 1 to 1,000? You'd have to write 1,000 lines! That's not practical.

With a loop, we can do the same thing in 2 lines:

✅ With a Loop
for i in range(1, 6):
    print(i)
💡
Loops save time, reduce mistakes, and make code easier to read. That's why they're one of the most powerful tools in programming.

The for Loop

A for loop is used when you know exactly how many times you want to repeat something.

Python Syntax
for i in range(start, stop):
    # do something with i

Example 1 — Print 0 to 4:

Python
for i in range(5):
    print(i)
# Output: 0, 1, 2, 3, 4

Example 2 — Print 1 to 5:

Python
for i in range(1, 6):
    print(i)
# Output: 1, 2, 3, 4, 5
💡
Important: range(5) stops before 5 — it goes 0, 1, 2, 3, 4. range(1, 6) starts at 1 and stops before 6 — it goes 1, 2, 3, 4, 5.
The while Loop

A while loop is used when you want to repeat something until a condition changes. You might not know in advance how many times it will run.

Python Syntax
while condition:
    # do something
    # (change the condition, or you'll loop forever!)

Example — Count from 0 to 4:

Python
count = 0
while count < 5:
    print(count)
    count = count + 1
# Output: 0, 1, 2, 3, 4
⚠️
Warning: If you forget to change the condition (like count = count + 1), the loop runs forever. This is called an infinite loop!

When to Use Which Loop

Both loops can do the same job, but one is often clearer than the other. Here's a guide:

Use a for loop when… Use a while loop when…
You know exactly how many times to repeat You repeat until a condition changes
Example: "Do this 10 times" Example: "Keep going until the user says stop"
Example: "Sum numbers from 1 to 100" Example: "Keep asking for input until the user types 'done'"
Example: "Print the multiplication table for 7" Example: "Keep simulating a bouncing ball until it stops"
💡
Rule of thumb: If you can count the repetitions in advance, use for. If not, use while.
Math Example: Sum of 1 to 10

Let's use a for loop to add up the numbers 1 through 10:

Python Program
total = 0
for i in range(1, 11):
    total = total + i
print("Sum =", total)
# Output: Sum = 55

Let's trace through the loop:

  • Start: total = 0
  • i = 1: total = 0 + 1 = 1
  • i = 2: total = 1 + 2 = 3
  • i = 3: total = 3 + 3 = 6
  • i = 4: total = 6 + 4 = 10
  • … continues until i = 10
  • Final total = 55
💡
This is much easier than writing 55 + 45 + 36 + 28 + 21 + 15 + 10 + 6 + 3 + 1 by hand!

Guided Practice: Average of 5 Scores

Let's use a for loop to find the average of 5 test scores:

Python Program
total = 0
for i in range(5):
    score = float(input("Enter score: "))
    total = total + score
average = total / 5
print("Average =", average)

How it works:

  • The loop runs 5 times.
  • Each time, it asks the user for a score and adds it to total.
  • After the loop, we divide total by 5 to find the average.

What if we don't know how many scores? Use a while loop:

While Loop Version
total = 0
count = 0
while True:
    score = input("Enter score (or 'done'): ")
    if score == "done":
        break
    total = total + float(score)
    count = count + 1
print("Average =", total / count)
💡
The break statement stops the loop immediately. Here, it stops when the user types "done".

Challenge — Nested Loops

Example — print a triangle of stars:

Python

Key Takeaway

Loops let programs repeat steps without writing them many times. Use a for loop when you know the number of repetitions (like range(5)), and a while loop when you repeat until a condition changes. Always remember to change the condition inside a while loop, or you'll create an infinite loop. Loops are one of the most powerful tools in programming — they save time, reduce errors, and make code elegant.
