Final Project: Simple Program for Math/Science

This is your chance to become a real programmer! You'll design, code, test, and present your own math or science program using everything you've learned: variables, conditions, loops, and input validation. This is the culmination of Indicator 2!

Project Overview

Your mission is to design and code a simple program that solves a math or science problem. Along the way, you'll use everything you've learned in this unit:

📦

Variables & Data Types

Use int, float, and str correctly for your inputs.

🔀

Conditions (if/elif/else)

Make decisions based on user input or calculation results.

🔁

Loops (for/while)

Repeat steps when needed — for multiple inputs or calculations.

🛡️

Input Validation

Handle invalid inputs gracefully — no crashes!

🧪

Testing & Debugging

Test with normal, boundary, and invalid cases.

🎤

Presentation

Explain your program clearly to the class.

💡
Key idea: This isn't just about writing code — it's about solving a real problem and showing your thinking.
Choosing Your Project

Here are 8 project ideas to choose from. You can also propose your own topic — just make sure it involves math or science!

🚀

Motion Equation

s = ut + ½at² — calculate displacement from velocity, acceleration, and time.

📐

Area Calculator

Calculate the area of different shapes (rectangle, triangle, circle, etc.).

❤️

BMI Calculator

Calculate BMI and print the health category with tips.

🧪

Density Calculator

Density = mass ÷ volume — with unit conversion.

🏃

Average Speed

Average speed = total distance ÷ total time, for multiple trips.

🌡️

Temperature Converter

Convert Celsius to Fahrenheit and back, with validation.

💰

Simple Interest

I = P × R × T ÷ 100 — calculate interest earned.

⚡

Ohm's Law

V = I × R — calculate voltage from current and resistance.

Step 1 — Plan Your Project

Before you start coding, plan carefully. Write your plan with these 5 parts:

  1. Problem statement.
    What is your program going to do? Write a clear sentence.
  2. Formula or logic.
    What math or science formula will you use?
  3. Inputs.
    What values will the user enter? What data types?
  4. Output.
    What will the program display?
  5. Features.
    Will you include a condition? A loop? Input validation?
💡
Get approval first. Show your plan to your teacher before you start coding.
Step 2 — Write the Code

Now it's time to write your Python program. Your program should include:

📦

Variables

Use clear names and the correct data types (float for decimals).

🔀

At Least 1 Condition

Use if/elif/else to make a decision or categorize a result.

🔁

At Least 1 Loop

Use a for or while loop to handle multiple inputs or repetitions.

🛡️

Input Validation

Check that inputs are valid (positive numbers, correct range).

Sample template for a math program:

Python Template
# Ask for input
x = float(input("Enter x: "))

# Validate input
if x <= 0:
    print("Error: x must be positive.")
else:
    # Calculate result
    result = x * 2 + 5
    print("Result =", result)

Step 3 — Test Your Program

Test your program with three kinds of cases:

Test Type Purpose Example
Normal case A typical input the program should handle A reasonable number
Boundary case An input at the exact edge of a range 0, 1, or exactly at a threshold
Invalid case An input the program shouldn't accept Negative numbers, non-numeric input

Create a debugging log:

Test Input Expected Actual Fix
Normal ___ ___ ___ ___
Boundary ___ ___ ___ ___
Invalid ___ ___ ___ ___
💡
Did your program crash? That's okay! Find the bug, fix it, and test again. That's what real programmers do.
Step 4 — Present Your Work

Your presentation should last 3–5 minutes. Include these 5 parts:

  1. Problem statement.
    What problem are you solving? Why does it matter?
  2. Your formula or logic.
    Explain the math or science behind your program.
  3. Your program.
    Show the code. Explain the key parts: variables, conditions, loops.
  4. Your test results.
    Show what happened when you tested it (normal, boundary, invalid).
  5. What you learned.
    What was the hardest part? What are you proud of?
💡
Presentation tips: Speak clearly. Point at your code when explaining. Don't read from notes — explain your thinking in your own words.
