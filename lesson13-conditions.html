Conditions (if/else) for Decision Making

So far, your programs just follow steps in order. But what if a program needs to make a decision? For example: "If a student's BMI is too high, print a warning." In this lesson, you'll learn how to use if, elif, and else in Python to make your programs smart.

Warm-Up: Decisions in Daily Life

You make decisions all day long. Think about this one:

☔
"If it rains, I'll take an umbrella. Otherwise, I'll wear a hat."

We can write this decision using symbols:

Decision
IF rain THEN take umbrella ELSE wear hat

This is a condition — a decision that programs can make too!

What Are Conditions?
Definition
A condition is a test that is either True or False.
Programs use conditions to make decisions.

In Python, we write conditions with if, elif, and else:

Python Syntax
if condition:
    # do something
elif another_condition:
    # do something else
else:
    # do this if nothing else is true
💡
Remember: Only one branch runs. Python checks each condition in order, top to bottom, and stops as soon as one is True.

Comparison Operators

To build conditions, we use comparison operators. These compare two values and return True or False:

Operator Meaning Example Result
> Greater than 5 > 3 True
< Less than 5 < 3 False
>= Greater than or equal to 5 >= 5 True
<= Less than or equal to 4 <= 3 False
== Equal to 5 == 5 True
!= Not equal to 5 != 3 True
💡
Watch out: == (double equals) is for comparison. = (single equals) is for assignment. Mixing them up is one of the most common mistakes in programming!
Simple Example: Positive, Negative, or Zero?

Here's a Python program that checks if a number is positive, negative, or zero:

Python Program
num = float(input("Enter a number: "))

if num > 0:
    print("Positive")
elif num < 0:
    print("Negative")
else:
    print("Zero")

Let's trace through the logic:

  • If the user enters 5: 5 > 0 is True → prints "Positive"
  • If the user enters -3: -3 > 0 is False, then -3 < 0 is True → prints "Negative"
  • If the user enters 0: 0 > 0 is False, 0 < 0 is False → prints "Zero"
💡
Notice: The else block only runs if all previous conditions are False.

Guided Practice: BMI Categories

Let's write a program that calculates BMI and prints the correct category.

BMI Formula
BMI = weight (kg) ÷ height² (m²)

BMI Categories:

  • BMI < 18.5: Underweight
  • 18.5 ≤ BMI < 25: Normal
  • 25 ≤ BMI < 30: Overweight
  • BMI ≥ 30: Obese

The Python program:

Python Program
weight = float(input("Enter weight (kg): "))
height = float(input("Enter height (m): "))
bmi = weight / (height * height)

print("BMI =", bmi)

if bmi < 18.5:
    print("Underweight")
elif bmi < 25:
    print("Normal")
elif bmi < 30:
    print("Overweight")
else:
    print("Obese")

Test with sample values:

  • Weight = 50, Height = 1.6 → BMI = 19.5 → Normal
  • Weight = 40, Height = 1.6 → BMI = 15.6 → Underweight
  • Weight = 70, Height = 1.7 → BMI = 24.2 → Normal
  • Weight = 85, Height = 1.7 → BMI = 29.4 → Overweight
  • Weight = 100, Height = 1.7 → BMI = 34.6 → Obese
💡
Notice how the conditions flow: If BMI is 19.5, the program checks bmi < 18.5 (False), then bmi < 25 (True) → prints "Normal" and stops.

Key Takeaway

Conditions let programs make decisions. In Python, we use if (first condition), elif (additional conditions), and else (the fallback). Comparison operators like >, <, >=, <=, ==, != are used to build conditions. Remember: only one branch runs — Python checks each condition in order and stops as soon as one is True.
